# Ivanna Haiovska | Portfolio

A modern responsive portfolio website showcasing my skills, projects, and contact information.  
Built to present my work as a Full-Stack Web Development student in a clean and user-friendly way.

## Demo
[Live Demo](https://ivanna-dev-portfolio.netlify.app/)

## Features

- Responsive layout for desktop, tablet, and mobile
- Animated hero section with particle background
- Fixed navigation with mobile burger menu
- Smooth scrolling and active section highlighting
- About, Skills, Projects, and Contact sections
- Reveal-on-scroll animations
- Contact form with validation and EmailJS integration
- Project cards with live demo and GitHub links
- Clean dark theme with purple accent styling

## Technical Notes

- HTML5 semantic structure
- CSS3 with Flexbox, Grid, and responsive breakpoints
- Vanilla JavaScript (ES6)
- DOM manipulation and event handling
- Form validation and email sending with EmailJS
- Canvas-based particle animation in the hero section
- Accessibility improvements with aria labels and keyboard focus styles

## Responsive Design

- Mobile-friendly navigation menu
- Flexible grid layout for skills and projects
- Optimized hero section for smaller screens
- Centered project screenshots with object-fit: contain for consistent presentation
- Scalable typography and spacing for different screen sizes
